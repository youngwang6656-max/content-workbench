# 内容工作台 · 通用版 1.0.0

在自己的电脑上管理资料、创作模拟帖文与评论，并保留意见、历史版本和中文回译。支持自定义图片标识，不预设公司 Logo。

## 启动

Windows 解压后双击 **启动内容工作台.cmd**。首次启动按现有启动器准备免费 Python 环境及依赖，不需要管理员安装，不会自动开启付费 API。

默认本机地址：http://127.0.0.1:8766/ 。个人数据默认保存在 `%LOCALAPPDATA%\content-workbench`，与原版的 8765 端口和数据目录分开。也可用 `CONTENT_WORKBENCH_DATA_DIR` 指定独立目录。

首次使用创建个人账号，该账号就是本机唯一管理员。源码没有预置密码、登录会话或远程管理入口。已有安装使用自己的管理员账号；不要把本机账号数据库发给其他人。

## 自定义图片

登录后点击左上角的工作台标识，或到“设置与用量 → 工作台标识”。支持上传、更换及移除静态 PNG、JPEG、WebP，最多 5 MB。图片保留颜色、透明背景及比例，显示在侧栏、登录页及浏览器图标位置。自定义图片保存在当前安装，源码分发不携带你的图片。

## 主要功能

- PDF、PPT、Word、图片、表格、链接和文字资料；批量上传、读取与分析。
- 模拟帖文、评论及 CB；从任意合法起点推进到英文稿与确切中文回译。
- 全站搜索原帖、批量生成独立评论、后台搜索与进度保存。
- 原稿、修改意见、候选、通过记录和依赖关系保留；英文词数及干净复制。
- 官方订阅与自配 API 分开管理，API 默认关闭，预算与未知费用保护沿用。
- 品牌项目迁移、原始对话导入、完整业务备份及源码分享包。

所有帖文和评论仅供模拟分析，程序不会代为向社区发布。
