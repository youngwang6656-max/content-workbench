# 内容工作台通用版 用户使用手册

适用版本：1.0.1。工作台用于整理品牌资料、创作模拟帖文与评论、保存意见和版本；不会向 Reddit 或其他社区实际发送内容。主题、思路、CB、意见与回译使用中文，帖文标题、正文和评论成品使用英文。

## 1. 第一次使用：从启动到第一条成品

1. 将程序解压到自己的文件夹，保留原有目录结构。双击“启动内容工作台.cmd”。首次启动可能需要下载免费的 Python 环境与依赖，请保持网络可用并等待日志完成。
2. 浏览器打开本机工作台，默认地址是 http://127.0.0.1:8766/。后台程序运行期间网页才可访问；关闭网页通常不会停止后台。
3. 输入自己的名称或昵称，点击“进入工作台”。无需注册或密码；已有资料继续保留。名称仅用于显示，同一安装共用资料，官方模型登录另外配置。
4. 在“设置与用量”完成官方 ChatGPT 登录，检查连接与账户模型目录，再保存模型配置。官方登录页面由本人完成，不要把密码或验证码交给别人。
5. 创建品牌，例如 TOPDON 或 70mai。在“品牌资料”放入该品牌的文件、文字或公开链接。
6. 点击“开始新任务”，写一句自己的想法。先查看节点默认可以选英文成品。生成后查看英文和中文回译，点击“通过”或“添加意见”。

启动需要的是后台程序，不是 PowerShell 窗口本身。使用一键启动器即可；如果自行从终端启动，不能把运行中的服务直接关闭。电脑休眠、退出程序或关机会中断运行中的模型请求。

## 2. 页面和侧栏怎么用

- 开始新任务：新建帖文、评论或独立中文 CB。
- 中文译读：随时把正在看的英文材料译成中文，不推进写作阶段，也不修改英文原文。
- 工作台：按品牌查看帖文、评论、CB 和进度，搜索任务名称或内容。
- 品牌资料：保存当前品牌的产品材料、策略和附件。
- 全局规则与资料：保存所有品牌都能使用的通用规则和写作偏好，不应在这里放只属于某个品牌的产品事实。
- 项目迁移：导入真实交接资料，查看缺失清单、补传附件、导出品牌项目。
- 使用手册：本手册，可以搜索章节，也可以下载用户版和智能体版。
- 设置与用量：官方连接、模型配置、API 服务商、价格、预算、更新、完整备份。
- 使用名称：修改当前称呼或重新输入名称，没有密码设置。

桌面侧栏的顶部和底部固定，品牌项目区域单独滚动。品牌下的 A、c 双横线、方框 B 分别表示帖文、评论和 CB。左下方显示当前配置，以及手动/自动、已登录/待验证等状态；详细模型在设置中查看。

## 3. 品牌项目、排序与置顶

一个品牌是一个项目。其任务、产品资料、意见和客户偏好单独保存；新建品牌不会混入其他品牌的资料。

品牌列表排序入口有“添加时间”和“最新修改”，均将较新项目放在前面。“最新修改”依据任务、稿件、意见、资料、规则等内容更新，不按打开页面或刷新状态计算。已置顶的品牌仍在列表前方；原有手动排序也可使用。排序选择保存在当前浏览器本机。

品牌右侧三个点可管理名称、置顶、移动和合并。合并会保留原始记录并生成备份，先阅读预览；撤销不能覆盖合并后新增的改动。名称修改不会删除原稿。

## 4. 提交品牌资料：放进去即可

在品牌资料页一次选择多个文件，或把文件拖入指定上传区域。支持文字、PDF、Word DOCX、PowerPoint PPTX、Excel XLSX、CSV 和常用截图图片；也可以直接粘贴文字或提供公开网页链接。每个文件上限为 20 MB。

文件先保存在本机，然后建立页/段索引，模型按已授权配置自动读取、分析和整理。品牌原件、提取文字和历史分析都会保留。长文档需要分段，进度以实际覆盖的页数显示，不把只读了几页说成已读完。

资料来自品牌仍需要区分两件事：可以采纳为工作依据；具体规格、兼容性、价格或技术结论是否经独立来源核实。采纳不等于所有说法已被验证。扫描 PDF、很小的截图文字、SmartArt 或复杂图表可能不能完整解析，工作台会显示真正缺失部分。

上传窗口中的成功和失败按文件分别记录。部分文件失败时可只重试失败项；不要反复把全部文件重新上传。批量归档用于暂时不使用的资料，原记录保留。已绑定评论的原帖快照不能当普通资料改写，换原帖请新建评论任务。

## 5. 全局规则与品牌偏好

全局规则可放自然表达、标点、通用审核要求等；品牌规则可放品牌写法、人物口吻或客户偏好。工作台会结合本品牌规则和全局规则生成。

意见记录中的“采纳为偏好”会把选定文字加入规则版本。只适用于一条稿的意见通常不要提升为全局规则，否则可能影响其他任务。规则更新后受影响的旧稿可能需要核对，旧稿仍会保留。

附件、原帖、网站和历史对话是待理解的资料，不会被当成可以执行本机命令或修改账号设置的指令。

## 6. 帖文：任意输入，直达想看的节点

帖文可以从中文主题、思路、中文大意、CB 或已有英文起步。无需为了推进流程把每个中间阶段都补齐。

“先查看哪一步”是希望停下来判断的节点，不是永久终点。例如先选“中文思路”，模型生成后你可以添加意见，或点击“通过并直达英文成品”。模型会参考节点的大意重组英文，不机械逐句照搬。

帖文和评论的固定终点均是英文成品及对应回译。独立 CB 任务以中文 CB 为成果，不强制生成英文。

英文成品前会使用当前写作配置尝试核验可能写入的具体信息。可访问的来源和未核实项显示在稿旁。使用不支持联网的 API 时不会暗中切到 Plus，无法核实的内容会明确提示。

## 7. 社群和多版本帖文

社群可由 AI 推荐，也可自己添加，数量 1–5 个。每个社群至少一篇版本，同一社群可生成 1–3 篇候选。社群和候选可以分别推进，不必一起通过。

AI 推荐后会先停在社群选择处，不立即写稿。勾选要保留的社群、为各社群设置帖文数量，点击“确认社群并生成稿件”。取消勾选的社群不生成。推荐结果会保存，刷新页面后仍可确认；未确认时再次运行不会重复推荐。已确认方案用于后续继续和返修，重新推荐或修改方案后再确认。

“查询规则与讨论风格”读取该社群公开规则和帖子样本。结果会显示取得的规则、样本数量、查询时间及来源；少量样本只用于有限判断，不能代表全部社群生态。

最近 24 小时内的可用证据可以复用，避免重复读取与模型归纳。需要核对最新变化时点击“刷新”。规则页访问受限时会尝试官方联网工具读取社群首页、版主公告和可见帖子；不会绕过登录、验证码或访问限制。

如果仅拿到规则或少量样本，已有内容仍显示，缺项单独说明。所有稿件只用于模拟分析，社区禁止推广等规则不会阻断模拟创作，但结果不代表获准真实发布。

## 8. 评论：一篇原帖，一个任务

先选原帖，再创建评论任务。原帖来源有五种：

全站搜索或直接输入链接得到的原帖，在任务页的原帖标题右侧显示链接和“复制链接”：点击链接在新标签打开，复制保留完整 URL。纯文字、截图等没有链接时不显示，也不会虚构链接。

1. 引用本品牌正在进行的帖文及确切版本。
2. 粘贴原帖标题和正文。
3. 提供 Reddit 原帖完整链接或 redd.it 短链接。
4. 上传原帖截图，识别清晰可见部分，不补造被截掉的文字。
5. 全站搜索适合评论的原帖。

每个任务创建后原帖固定，包括正文快照、链接、截图附件或自有父稿版本。编辑任务可以修改评论意图和查看节点，不能把原帖换成另一篇。要换帖请新建任务。旧版没有绑定原帖的任务可补绑定一次。

评论默认 40–90 个英文词。希望长评、极短评或指定词数时，直接写在意图或意见里。模型先回应原帖的具体问题，再自然带入相关信息，不应把评论写成参数清单或统一客服模板。

## 9. 全站搜索和批量铺评

设置搜索意图、目标数量 1–5 篇、时效 0–30 天。0 表示本机今天，1 表示最近 24 小时。搜索按品牌产品类别和读者需求寻找，不要求原帖出现品牌词。

候选显示高/中/低推荐程度、中文适合理由、切入点、日期依据和原帖摘录。公开检索可能遗漏，找不到足量时如实说明，不会伪造链接或日期来凑数。只有日期或相对时间的结果会注明精度限制。

候选默认全选，可取消不需要的篇目。填写共同评论意图后点击“生成所选铺评”，所选每篇分别成为独立任务；每条根据自己的原帖理解，不共享人物故事或事实。

关闭弹窗、切换页面或刷新浏览器不会停止后台搜索，再次进入同品牌的全站搜索可恢复进度、候选、勾选和意图。主动点击“停止搜索”才停止。后台程序本身退出会中断搜索，重启后保留记录但不自动重复调用。

连接、额度、预算或超时失败会暂停本批后续任务，完成的稿件仍保留；检查问题后手动继续。重复提交同一批请求不会创建第二份相同任务或重复消耗模型额度。

## 10. 自有英文帖文生成铺评

英文帖文详情和候选卡可点击“生成铺评”，直接关联确切英文版本，创建并运行评论与中文回译。同一个入口重复点击会打开已关联任务。

多版本英文帖文可以勾选多篇后批量生成，每篇对应自己的独立评论任务。父稿更新后原评论仍保留，但会提示关联依据变化；可点击“围绕新版本新建任务”，不会替换原评论的来源。

## 11. 通过、意见、移除和版本历史

生成完成仅表示有可查看结果，不等于你已经通过。中途节点通过与最终英文通过分别记录。新意见生成新版本后，旧通过记录只属于旧版本，需要检查新成品。

添加意见直接说要保留什么、调整什么。若只改一处，可以选择原文或粘贴允许修改的确切片段；范围外文字应保持原样。原稿、每轮意见、新稿和差异记录都会保留。

多社群候选可移除不需要的一篇，最后一篇不能移除；移除后不再继续生成，历史仍可查看，符合当前方案时可恢复。

历史主管/客户意见仍保留其原始来源和范围；日常入口统一为“添加意见”，无需反复区分身份或走强制复核流程。

## 12. 中文译读、回译和英文词数

英文在任何阶段都能点击“中文译读”，方便快速判断，不需要等最终成品。正式中文回译只根据确切英文标题和正文生成，不根据旧中文重新写作。

同品牌、完全相同英文且适用翻译规则一致时，可以复用正确译文，仍保存关联当前英文的新回译版本。存在待处理回译意见或无法核对的译文时不复用。

英文稿自动显示正文词数；帖文还显示标题和合计。统计在本机进行，不消耗订阅或 API。英文单词、数字、URL 各计一个；缩写和带连字符名称计一个；中文说明、审核文字和回译不计入。词数不是模型 token 数，也不是实际计费数量。

手动编辑英文时，词数随输入更新。复制正文仍只复制内容，不附带词数、说明或审核状态。

所有英文候选和英文任务详情在“中文译读”旁都有“复制”。帖文复制标题、空行和正文；评论通常只有正文。不会复制中文回译、模型说明、词数或审核状态。浏览器禁止剪贴板写入时，会弹出已选中的干净内容供复制。

## 13. Plus 与 API：两个不同通道

Plus/ChatGPT 订阅使用官方认证及账户可用目录；API 使用服务商密钥和独立按量计费。订阅登录成功不等于当前额度可用，也不等于 API 已启用。

配置可以命名为配置1、配置2等，分别保存模型分工。手动模式使用所选配置；自动模式需明确选择订阅默认配置和已授权 API 备用配置，只有核实额度达到阈值或用尽时才切换。未知额度、网络错误或登录失效不会触发付费切换。

“剩余 10%”指五小时窗口剩余降到 10%，不是已用达到 10%。额度恢复后可回到默认配置。工作台不会使用 credits，也不会替你升级订阅或开通 API。

## 14. 模型分工和节省额度

默认写作、返修、资料分析和 CB 使用高推理强度；中文回译使用较低强度，社群证据归纳使用中等强度。具体模型不自动更换，每份订阅配置可覆盖各环节强度，实际能力以账户目录为准。

若较轻默认强度不被当前模型支持，会使用该模型目录中可用的较轻强度。明确选择了不支持的强度则暂停并提示，不悄悄替换模型。API 各环节可选择自己的模型，价格需逐模型核对；不向所有第三方接口强行发送不支持的推理参数。

字数统计、品牌排序、文件保存、手册和复制均本机处理。相同原文译读、同文回译和近期社群证据会尽量复用。写作不会为了机械风格修正额外调用一轮模型。

降低强度、使用较轻模型和减少重复请求有助于控制等待及消耗，但工作台不能保证固定的订阅扣额比例。高质量写作和复杂图表分析不要只为省额度使用无法完成任务的模型。

## 15. API 价格与预算

API 默认关闭。保存地址、密钥、模型或配置不会开启付费生成。密钥留在本机，不随品牌包和业务备份分享。

生成前要求当前账户模型目录及核对过的当期价格；目录一般需在 24 小时内读取，价格按服务商与具体模型确认。共享额外现金预算上限为每月 20 美元，初始停止线 18 美元。订阅费用与 API 新增费用分别理解。

API 返回完整用量后记录费用，缺少用量或失败的在途请求保留待核实费用，后续付费调用暂停。不要用恢复旧备份来抹去支出；恢复不会让已知费用倒退。付费图片和不支持的联网能力不会自动开放。

## 16. 项目迁移和缺失附件

完整度优先时，先在原 ChatGPT 账号的“设置 → 数据控制 → 导出数据”申请原始导出，下载后核对里面是否包含需要的对话。[官方导出说明](https://help.openai.com/en/articles/7260999-exporting-your-chatgpt-history-and-data)。订阅登录不能直接授权工作台获取云端全部历史，让 GPT 写交接摘要也不能补齐未读取的内容。

在“项目迁移 → 从原始对话迁入”选择原始 ZIP、conversations.json 或多个编号 JSON 分卷，点击“读取对话清单”。合计最多 100 MB、100 个文件；ZIP 展开最多 200 MB，超过时可先解压，仅选择对话 JSON。文件之间重复的对话会明确报错，不能同时选总文件和其重复分卷。

按标题筛选，同一品牌的对话一起勾选；默认不勾选。可用“勾选当前列表”，被筛选隐藏的已有选择仍保留，“清空选择”可全部清除。预览显示实际对话、消息、分支和文字记录数量，长消息自动分段而不截断。选择结果在服务器临时保留 30 分钟；切换页面或重启后重新读取文件。

确认后创建独立新品牌项目，保留现有项目。各分支原文存入可搜索历史，并成为“原始对话”品牌资料，后续可按资料分析流程整理；不会自动把旧对话当作指令、已核实事实、当前稿件或审核通过记录。所选 JSON 的全部字段保存在“下载迁入原始文件”中，不保存账户导出里的其他品牌对话和其他账户文件。原始消息无日期时不补造；非文字消息保留原始引用并列出缺项，图片与附件原件请在品牌资料页另外补传。

导入和统计在本机完成，不消耗模型额度。大型选择在写入前检查能否按现有项目包限制导出恢复；超过时先分批勾选对话。迁入后的品牌导出和业务备份包含这些原文与源档案。原始文件不包含的云端历史、自定义指令和记忆需要另行提供；不能凭文件条数宣称整个云端项目已完整迁移。

先导入真实旧项目 JSON/ZIP 并阅读预览，确认品牌、规则、历史和缺失项，再提交。交接摘要不等于完整原文；没有提供的附件不会凭空出现。

缺失原件可以从资料入口补传到原导入资料。已经固定在评论任务里的快照不能被补传改写；先补齐原资料，再围绕完整来源新建任务。

品牌导出包含该品牌任务、来源、附件和必要的全局规则快照，不把本机账号、密钥、实时运行队列或其他品牌业务带走。接收端的全局规则不会被品牌快照静默覆盖。

## 17. 备份、分享和更新

完整业务备份用于恢复自己的项目、稿件、规则和附件；分享程序请使用源码发布包，不要把整个本机数据目录交给别人。每人独立安装、输入自己的名称并使用自己的模型账户。

恢复前先停止写作、资料处理和后台搜索，工作台会保留回退副本。恢复后检查历史和费用，再手动继续，不会自动重放中断请求。

更新入口支持配置公开 HTTPS 清单。目前没有正式公网更新源时，清单模板不会自动发布到外网。检查和下载由你主动操作，不自动覆盖使用者自己修改的源码。更新前保存输入并备份，版本不同会提示重新启动后台和刷新网页。

## 18. 常见问题怎么判断

- 网页显示“127.0.0.1 拒绝连接”：通常是后台未启动或已经退出。重新使用一键启动，查看启动日志，单纯刷新网页不能替代启动后台。
- 网页和后台版本不同：保存输入，停止旧程序，启动当前目录的程序，再刷新；不要同时运行多个目录的旧版。
- “已登录”但“无法核实订阅额度”：认证与额度读取是不同检查，先检查官方连接；不要因为网络失败就反复点生成或自动开 API。
- 资料“待你处理”：点击带下划线的“资料”入口查看具体文件、未读页、缺失原件或补充要求。已经完整取得的内容不会因单页失败被删除。
- Reddit 403、规则或正文访问受限：看保留的部分证据；可用官方联网查询、公开原帖文字或截图补充，不绕过验证码或冒充读取成功。
- 原帖或父稿已变化：查看固定版本；需要新来源时新建任务，不把旧评论替换到另一篇。
- API 不可用：分别核对协议、地址、真实模型目录、价格、密钥、授权及预算；不要把读取模型成功当作生成成功。
- 文件超过 20 MB：压缩图片、另存优化 PDF 或拆成有明确页码的几个文件，保留原件。

## 19. 如何让任意 AI 帮忙

下载“智能体使用手册”，或把程序目录中的 waypoint/manuals/智能体使用手册.md 交给能读取本机文件的 AI。说明自己的症状、当前版本、实际项目目录和操作步骤，提供脱敏日志或截图。

不要交出密码、验证码、API 密钥或认证文件。AI 能否操作本机取决于其工具；只有聊天能力的模型可以解释问题和提出步骤，不能声称已经运行你的程序。

可直接复制：请阅读 waypoint 的用户手册、智能体使用手册、AGENTS.md、CODEX_HANDOFF.md 和 README.md。先确认我的真实电脑、目录与正在运行的版本，保留资料、原稿和意见，改动前备份，依据实际报错做最小修复。不要自动开启 API 或扩大费用；模拟测试与真实模型验收分开记录。

## 20. 一次典型工作

以品牌行车记录仪为例：建立品牌并放入产品资料 → 写中文想法并选英文节点 → 推荐或选择社群，读取规则与有限样本 → 生成各社群候选英文及回译 → 按词数和内容判断，通过或添加意见 → 选中需要的英文版本生成铺评 → 评论任务分别查看与修改 → 导出品牌或下载完整备份。

如果目的是围绕自然用户帖子评论：先全站搜索需求 → 勾选合适原帖 → 统一填写评论意图 → 每篇独立生成英文与回译。无需先创作自己的帖文，也无需逐个重复建立相同流程。
